# Shifumi

Petit jeu de **Pierre, Feuille, Ciseaux** réalisé en HTML, CSS et JavaScript.

Accessible sur ce lien : https://paulmunoz14.github.io/shifumi/

## Fonctionnement

Le joueur choisit entre :

* Pierre
* Feuille
* Ciseaux

L'ordinateur fait ensuite son choix et le résultat de la partie est affiché.

## Technologies utilisées

* HTML
* CSS
* JavaScript

## Lancer le projet

Aucune installation n'est nécessaire.

Il suffit d'ouvrir le fichier `index.html` dans un navigateur web.
